# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Текущее состояние

Это ещё не кодовый проект: нет git-репозитория, манифеста пакетов, сборки, тестов, линтера, CI. Команд сборки/запуска/тестов не существует — не выдумывать их, а проверять перед использованием.

Единственный материал — `чат о рынок Сочи сервисных компаний_сайт.md` (~1050 строк, UTF-8): сохранённая переписка на русском, а не спецификация. Имя файла с пробелами и кириллицей — в shell-командах брать в кавычки. Подробные правила для агентов лежат в `AGENTS.md`; здесь только главное.

## Структура переписки

- Строки ~1–960: исследование рынка сервисных компаний Сочи и консалтинга по автоматизации для малого бизнеса (разделы 1–11, итог).
- Строки ~775–957: «Выкладка» — цитаты из других репозиториев (`tender-platform`, `Content_Factory`) и их инструментов (ruff, alembic, pytest, docker compose, nginx). К этому каталогу они не относятся, не применять их.
- Строка ~959 и далее: «Контекст: личный сайт-визитка» — единственный раздел, описывающий реальную задачу: цели, аудитории, структура сайта, размещение, открытые вопросы, следующие шаги.

## Планируемый проект: сайт-визитка

- Один сайт как хаб для четырёх аудиторий: владельцы малого бизнеса, интеграторы/агентства (субподряд), работодатели/HR, посетители с фриланс-площадок. У каждой — свой маршрут и своё главное действие; не смешивать «ищу работу», «продаю услуги» и «беру субподряд» в одном заголовке.
- Минимальный запуск: хаб, услуги, 3 карточки кейсов, страница для интеграторов, контакты, «обо мне»; резюме — ссылкой на PDF. Калькуляторы и дополнительные страницы — только после реальных кейсов.
- Каналы различаются UTM/параметрами (`?from=freelance|mailing|hh`) и первым экраном; кейсы не дублируются.
- Хостинг: GitHub + GitHub Pages или Cloudflare Pages, собственный домен. Стек не выбран (статический генератор или простой HTML/CSS) — перед созданием каркаса или фреймворка спросить пользователя. Конструкторы вроде Tilda не рекомендованы.
- Тексты сайта — на русском.
- Персональные данные не собирать: форма на статическом хостинге требует внешнего сервиса и попадает под ФЗ-152. Начинать со ссылки mailto или Telegram.

## Ограничения при работе

- Рыночные цифры, чеки, доли рынка, тарифы конкурентов и ссылки из переписки не проверены (переписка сама это признаёт). Не выдавать их за факты на сайте или в документах без проверки.
- Не выдумывать метрики кейсов: спросить пользователя, что сделано, какие измеренные результаты и какие инструменты использовались.
- В переписке есть личные планы поиска работы и контакты — не копировать в публичный репозиторий или на сайт без явного согласия пользователя.
